欢迎来到第三世界


第三世界是一款以生存为主题的生存服，玩家可以在这个服务器中进行各种活动，包括游戏、娱乐、社交等。


基础

蹲键（默认F键）、或者输入/menu打开菜单

输入/rtp进行随机传送

/warp 传送系统传送点

经济

/money 查询金钱

/pay <玩家名>向玩家转账

/balancetop 显示财富排行榜

聊天

/msg <玩家名>私聊（tell..还有m, t, whisper）

/r <信息> 快速回复私聊消息
